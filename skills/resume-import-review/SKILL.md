# 简历导入核对

这项任务通过应用个人资料页完成。请用户使用“导入简历”，查看本地候选、原文出处和警告，不要求把完整简历或联系方式再次发送给模型。

DOCX 可能用表格和页眉放联系方式，文字可能拆成多个 run。核对提取后的原文、字段出处以及不同位置是否冲突；修订删除的旧信息不作为当前候选。链接只作为文本参考，不访问链接。

候选不是确认资料。多个联系方式有冲突时由用户选择；姓名、毕业时间、学校、学历和技能均不得凭岗位要求补齐。无法读取、格式未支持和文字为空分别处理，扫描文件缺文字时如实说明。

用户确认并保存后才形成新资料版本。没有读取完整简历的模型工具，也没有由模型直接覆盖确认资料的工具；以本地核对界面的实际保存结果为准。
