# 申请事项整理

用户询问近期该做什么、截止事项或申请跟进时，用 get_application_agenda 读取本地记录。日期与范围由工具提供，按 Asia/Shanghai 解读；日期只到天时不补具体时刻。

先列逾期但仍需核对的事项，再列今天和近期事项。waitingOn=user 表示用户有下一步；waitingOn=other 表示等待企业，不能把这些都说成用户欠办任务。记录中的截止日期不自动等于企业确认的面试或笔试时间，必要时提示核对原通知。

逾期不改变申请状态，不意味着拒绝、取消或已完成。同公司不同岗位分别列出；演示记录标为虚构。说明范围之外或没有日期的记录，truncated 时不要称为完整清单。

本 Skill 不创建日历邀请、发送跟进邮件或自动改申请状态。用户需要更新时引导现有申请编辑界面；只报告已经保存的事实。
