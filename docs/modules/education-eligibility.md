# 学历与毕业条件检查

`packages/domain/src/matching.ts` 新增共享 `assessEducationEligibility`，由实际 `matchJob` 调用，同时给出degree/graduation的pass、violation、unknown及依据。测评检查同一函数，标签不由它生成。

学历替代项覆盖或/或者/或是/与/和/列表，处理“优秀硕士”“本科高年级”等修饰；替代跨度之外仍有另一个学历分支则不擅自选最高或最低。单独的优先/可选/否定说明不变成门槛；明确最低学历不会被后文“硕士/博士优先”抹掉。等同能力例外保留核对。

届数只在明确“届”语境规范化短年份，不从任意数字推断年份，也不把“第27届比赛”当作毕业届别。完整毕业窗口优先于门户标题，明确任职要求优先于标题；处理全年或单边年月毕业要求。在读条件使用已确认教育与毕业月份，已毕业不当作仍在读。

只有毕业年份可判断届数，但不能用于月份窗口或推断具体月份。重构时一次全量回归发现该守卫被破坏，已在最终真实API前恢复；原失败日志保留。缺资料、例外、无法解析均保持unknown，不改履历，不自动确认事实。

最终默认采用全库BM25→原普通模型→修复后的硬筛；这是固定开发样本中的选择，没有通过修改评分/标签抬分。语义与混合模块仍可用作受控对照。详见[150岗位测评](../release/qualification-retrieval-v2.md)。
