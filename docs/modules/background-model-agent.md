# 后台模型Agent与真实API配对回归

2026-10-19。用户要求实际模型驱动的后台Agent、baseline/新版与1/3/5并发结果，禁止提交申请。普通应用/资料/Keychain不读取或重启；专用百炼Key只经静默stdin进入内存。

## 测什么

受限网申草稿任务：读取确认资料键→观察真实官网控件→模型选择字段映射并调用执行工具→独立读回→准确报告缺资料/未支持项。不包含附件、声明、登录或最终提交，也不是岗位推荐质量测试。

主任务完成要求：实际Pi会话成功结束、真实API调用大于0、模型实际调用填写和最后读回工具、固定联系字段gold全部正确、没有向缺少资料的无关字段写入、没有执行器未解决故障、最终声明/附件未选中。字面回答“完成”、API成功或单个字段值正确都不能代替任务完成。联系字段值覆盖率、缺资料字段违规写入和任务完成率分别统计，不相加成一个好看的准确率；整份申请可提交性未验证。

## Agent与执行

Pi SDK仍是唯一会话内核。新增后台任务固定四工具：`read_confirmed_profile`、`inspect_form`、`fill_confirmed_fields`、`read_fill_status`。聊天原11工具不改成伪造的调用。每个岗位独立Pi历史、页面和一次性观察记录；模型不生成值/脚本/selector/坐标，只返回受控资料键。只有模型实际调用填写工具才执行，未映射字段不使用规则兜底。

宿主按确认资料版本、完整页面快照/URL/代次、原值与真实选项核对；只填已确认普通事实。新增语义校验拒绝将公司、链接、薪资、资格等无关字段映射成教育或联系资料键；拦截项返回缺资料提示。只有无写入的准备失败允许新观察后有界重试，部分/未知写入不盲目继续。取消会停止全部活跃任务，等待各页停止；最多5个后台任务，无OS输入、不抢焦点。

## Baseline定义

旧版没有可用的后台模型Agent，不能编造一个“旧版模型成绩”。baseline是本次最初模型Agent原型，已在语义校验修复前冻结13个项目源码依赖并打包，SHA为`fcce81844bf47f6bcb7381a3da96ac64710431fbad5a4ba6e1b9ce0f08fb9905`。只有隔离QA能加载此固定自有模块；网页、模型和普通renderer不能选择模块或关闭新守卫。baseline保留原型的简单准备和映射方式，原有写入/隐私守卫不移除；新版本补稳定准备、语义拦截和取消/恢复状态处理。

两边使用相同用户任务、模型、资料、工具名、系统提示、API/工具预算。每任务最多6次API、10次工具、90秒；单API20秒、不自动重试、输出上限1800 token。每次真实服务响应记录HTTP状态、SDK实际usage和耗时；失败usage未知不补0。模型为百炼北京`qwen-flash`，账单费用未知，不将SDK占位零价格当实际费用。

## 首轮固定协议

- 从已经采集的100家公司中，按原顺序取Lever前10、Greenhouse前10，共20家，20个精确URL；不排除已知不稳定网站来抬分。是产品回归面板，不是未见过的公开榜单。
- 固定四组：baseline并发1、新版并发1、新版并发3、新版并发5；每组同20家公司，每批5个岗位，合计80个Agent任务。实际活跃页峰值和模型请求区间重叠独立记录，不把配置数字当实测并发。
- 预先冻结联系字段事实及“缺资料字段必须保持空白”负向清单；最终值独立核对，直接违规写入即使之后被网页清空也计失败。首次原型试跑只检查联系人，漏掉非联系字段误写，原始报告保留并补独立纠错，不能用它当正式通过成绩。
- 四组各使用新的内存浏览器分区，组内共享该测试账号会话、每页独立；原账号/普通Cookie不使用。企业会话仅允许HTTPS GET/HEAD，拒绝提交、上传、自动保存写请求和WebSocket，因此不验证服务器接受。
- 正式运行前冻结案例、资料、源码/编译物和baseline哈希；运行期间不根据结果修改模型提示、执行器或评分。保留所有失败和未完成项。正式结果与试运行/26-token连接检查分开。
- 耗时同时报告整组wall、每任务服务P50/P95、排队延迟、任务/成功任务吞吐。整组wall包含固定独立审计开销；服务时长包含页面加载、模型和执行，但不含外部最终审计。固定顺序单轮，网络/服务缓存可能影响结果，不给统计显著性或人工提速结论。

## 试运行发现

连接检查1次HTTP200、26 token，不计任务。原型两站四组共40次真实请求，发现模型将当前公司、LinkedIn、期望薪资错映射成教育键。原始联系人通过回执不足以证明任务成功，已另存纠错并保留原始错误。加入语义拦截后的两站单组10次请求确认公司/链接/薪资未写；Verantos虽最终联系值一致，执行器没有完整稳定回执，仍未完成。以上仅用于修复，不加入正式80任务分母。
