# 数据和隐私

资料、浏览器登录态和申请记录保存在使用者电脑上。公开岗位的采集可以联网；在线助手会把所需任务上下文发送给使用者配置的模型服务。不要把「本地优先」理解为启用在线模型后完全离线。

简历解析候选需核对确认，来源保留。普通动作日志用于本机恢复，可能包含本机填写资料；不能当作匿名遥测直接分享。遥测导出只包含允许的动作、类别、计数、时间和已获得的用量，不包含字段值、原始网页 URL 或密钥。

证件号码在独立文件中使用 Electron safeStorage 系统加密，系统加密不可用时拒绝保存，不降级明文。界面只回显末四位；输入的新号码只在当前编辑过程中存在。证件不进入普通 AppState、普通导出、模型工具或 OTel。每次填写一个特定 HTTPS 页面时单独预览确认，只支持明确、唯一、空白的本人身份证号或护照号文本框。其他人、笼统证件框和已有内容不猜填。

该机制防止项目主动混用敏感数据，不承诺抵御已控制本机账户的攻击者。网页可能在输入时自动保存资料；用户确认填写就可能向企业发送该项资料，即使没有点击提交。最终申请提交、上传、声明和验证码由使用者处理。

发布副本采用文件白名单、新 Git 历史与内容检查。`npm run release:export -- --output=.publish/offerflash` 生成新副本，拒绝复制运行目录、凭据、原始日志、开发历史、未知二进制或 symlink。可用 `--deny-file=/path/to/local-private-markers.json` 额外检查私人标记；这个文件不会复制。自动检查有边界，新增自由文本、截图和二进制仍需人工审阅。
