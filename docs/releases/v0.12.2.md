# OfferFlash v0.12.2 · Private Demo

This prerelease is a macOS arm64 demonstration build, unsigned and not notarized. Save web drafts and quit the old app before switching. It retains the existing OfferAgent data identity; no testing resume, cookie or API key is installed into normal user data.

- Independent background Pi model tasks at concurrency 1/3/5, guarded local execution and actual model readback.
- Conditional/alternative names stay blank pending confirmation. Conflicting mappings are all rejected per field; other independently validated model mappings continue. Missing confirmed facts prompt the user.
- Same 20-company ordinary-draft regression and original scoring: 95% / 95% / 90%; 296 live API requests. Three original conservative legal-name flags and one pre-model page failure remain counted. No application was submitted.
- One separate full-career demo: 34 selected values matched, six career groups, 11272 tokens; ~107-second raw recording includes waits/manual choices. Estimated model cost ~CNY 0.0031, not a verified bill or whole-form speed benchmark.
- Full 1162 behavior tests and 44 packaged fixture assertions passed. These fixture checks are separate from the real-site metrics.

See [metrics and cost formula](../demo-metrics.md) and [real-model regression](../background-agent-conditional.md). Whole-form/server acceptance, arbitrary sites and unattended application submission are outside this prerelease. Login, verification, attachments, declarations and final submission require user action.
