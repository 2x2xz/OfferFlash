# 完整申请空间录制

这次展示完整的 OfferFlash 申请空间：左侧保留真实的聊天组件和本地资料核对回复，右侧是面壁智能实际登录后的网申页面，小闪跟随实际执行目标移动。不是把旧网页动图贴进界面，也没有重建企业表单。

岗位为[面壁智能「语言大模型算法研究员」](https://modelbest.jobs.feishu.cn/campus/m/position/7550158206165944639/detail)。人物“林小闪”及履历是演示资料，不代表真实求职者，不能据此认定满足该岗位的毕业年份等资格。姓名、邮箱与两段教育、两段实习、两个项目，共34项由生产原生执行器填写并核实；实际新增5组，最终6组，独立读回32个履历值一致。申请选项事先选好，账号绑定手机不改动，成片遮挡账号信息。附件没有上传，程序没有点击提交。

录制使用当前生产 React 界面、BrowserController、飞书执行器及闪电装饰，放在独立的录制宿主中，不读取普通用户资料库。左侧回复是宿主实际读取虚构资料和现场空白表单后生成的固定本地核对，不是在线模型生成；界面也明确显示未连接模型。没有虚构模型请求、工具调用或 token。完整窗口与内嵌网页每轮同时取图，按真实子视图位置合成；不是操作系统整屏录像，两个图层不承诺原子同步。仅去掉开头0.2秒尚未刷新的布局画面，随后保持原速，成片54.9秒，保留全部实际填写过程。尺寸和调色板压缩不承诺像素无损；录制开销计入时长，没有倍速，不作为人工提速对照。

为防止演示资料被网页自动保存，开始录制前阻止此独立网页的新请求；这可能使网页弹出网络错误提示，画面保留。不能声称企业已经保存或接受申请。自动整表审计仍保留4个保守提示：未选的同组“内推”以及三个内部搜索框。实际已有“无”、北京及两所学校的选择，独立原生辅助树再作语义复核，没有改写原始失败判定；附件、声明和服务器可提交性不在完成结论里。
