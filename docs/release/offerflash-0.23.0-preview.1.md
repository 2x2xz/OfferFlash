# OfferFlash v0.23.0-preview.1

即时问答与网申填写升级。macOS Apple Silicon 预览版，尚未签名、公证。

## 新功能

- **任务中直接提问**：Agent 需要补充信息时，对话输入区浮现问答块。可以选择选项，也可以输入自己的回答；确认后，Agent 自动继续当前任务，问题和回答保留在对话记录里。支持暂时跳过和停止；临时回答不会自动成为长期确认资料。
- **多个申请同时保留**：申请空间支持多标签页。切换标签保留原页面，各页面的填写结果分别显示；同站点标签共享登录会话。关闭或重启后能否恢复未保存内容，仍取决于网站。
- **减少经历填错、重复添加**：改善没有名称栏的实习和项目识别，修复职责与描述混淆、结束时间及“至今”状态处理。已有行尚未识别清楚时，阻止继续添加经历。
- **更可靠地处理复杂字段**：改善专业全称、籍贯、学历等选择控件；资料只有年月时，不擅自补具体日期。依据专业判断的近似类别仍作为待核对草稿。
- **模型连接本机加密保存**：使用系统加密保存连接配置，也支持仅本次使用；系统加密不可用时不降级为明文保存。

## 验证范围

即时问答已通过实际 Pi SDK 工具循环与生产界面的隔离验证，涵盖选项、自由文字、等待与同任务恢复、停止、上下文变更和重复提交检查。隔离验证没有调用付费模型，也没有访问企业网站。

部分填写修复已有真实页面字段回读。尚未完成所有网站、整张申请表的验收，不提供通用整表成功率或提速百分比。登录、验证码、声明确认与最终提交仍由用户完成。此预览版不包含任何用户资料库、简历、登录会话、API Key 或私有操作日志。

## 下载与使用

下载本次 Release 的 `OfferFlash-0.23.0-preview.1-mac-arm64.zip`，解压后使用 OfferFlash.app。在线 Agent 需要自行配置模型服务；源码构建需要 Node.js 22.19 或更新版本。

升级前请自行在官网保存草稿。发布安装包本身不会替换或重启已经运行的旧版应用。
