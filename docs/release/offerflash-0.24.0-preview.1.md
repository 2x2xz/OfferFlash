# OfferFlash v0.24.0-preview.1

这次预览版把即时问答接入实际填表过程：缺少普通资料或日期精度不足时，在对话输入区提问；回答经本机保存和确认后，原任务继续。人工等待期间停止运行进度，也不占填写执行预算。“无 / 不适用”和跳过会被记住，并可从卡片恢复询问。

填写后，对话区优先显示本轮实际回读的待处理卡片。每项可直接滚动、高亮到官网字段；只读定位不填写、不勾选、不提交。后台队列降为次要入口，结束状态不再显示持续运行。

明确字段先由受控执行器逐项匹配和核对，模型集中判断剩余字段映射、真实选项分类和有来源的说明草稿。修复无标题实习组识别，以及英文职位描述中的 capacity 被误判成 city 偏好问题。日期、学校／专业下拉和重复经历处理包含此前已验证的控件补丁。

同时修正原生可见性判断与实际点击坐标的取整不一致：边缘控件先滚入安全位置，再重新核对后点击。

闪电拖尾在真实目标之间移动时出现；快速输入成功后，保留原来的短暂淡出，不再被“已核实”状态立即抹掉。窗口失焦、减少动态效果、定位提醒和停止任务仍会关闭相关动效。

本版为预览：复杂控件、未暴露的经历区块和模型计划参数仍可能失败。附件、声明和最终可提交性需本人核对；应用不自动提交申请。面壁官网保留专用填写流程，其行为与通用填写链路分别展示，不把单站演示当作所有网站通过。

发布前完成类型检查、1,340 项回归、15 项拖尾复核，以及边缘坐标修正后的 63 项原生控件检查和安装包内真实问答／续填／定位检查。旧问卷与工具接口测试已适配当前流程，字段目标与不猜填、不提交、资料保护的断言保留；未暴露来源记录使结果保持 partial 的新规则单独标注。

源码与安装包经已知个人信息、凭据、绝对本机路径及运行数据检查；发布内容不包含个人资料库、登录状态、简历原件、专用 Key 或本机诊断轨迹。完整回归属于隔离检查，不是所有官网的通过率。

面壁官网首次录制保守中断，同一窗口定位后续填，最终 34 个已知目标一致。通用卡片对部分已选控件仍保守报告未核实；不宣称一次整表通过。
