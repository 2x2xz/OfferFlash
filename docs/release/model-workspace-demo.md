# 真实模型参与的完整网申演示

右侧是[面壁智能的语言大模型算法研究员网申页面](https://modelbest.jobs.feishu.cn/campus/m/position/7550158206165944639/detail)，左侧是实际运行的 Agent。人物“林小闪”、联系邮箱、教育、实习和项目均为虚构资料；学校和岗位是真实公开名称，不表示候选人满足岗位资格。

这次接入百炼 qwen-flash，真实执行了履历读取、表单观察和经历选择三个工具。模型根据页面的标签、控件类型和区块结构识别字段，给出联系人映射，并在每组经历写入前核对对应关系。实际输入和滚动由现有 BrowserController 原生执行器完成，原有焦点、页面和原值检查保留；最后模型再读回比较，本机也做精确核对。这是模型与站点执行器配合，不是模型直接看截图操作任意网页。

本轮 12 次请求均为 HTTP200，用量共 11,272 token。姓名、邮箱及两段教育、两段实习、两个项目，共 34 项读回一致，新增 5 组、最终共 6 组。学历、年月、实习职位、项目角色、项目链接和说明均包含在录制中。意向城市、无内推和没有正式工作经历由操作者选择；附件不上传，最终提交不执行。

上轮红色“网络错误”来自录制保护误拦了两个使用 POST 的查询：学校搜索和投递限制检查。核实官网客户端代码后，只放行面壁域名的这两个精确接口；草稿保存、简历创建、申请创建、上传及未知写入仍被禁止。本轮观察到的网络错误为 0，没有删除错误提示或伪造服务器响应。

录像来自独立录制宿主中的实际 React 界面和真实企业网页，每轮同时取图，按原生子视图实际位置合成；不是操作系统整屏录像，不保证两个图层原子同步。完整连续素材约 106.8 秒，包含模型等待和人工选项操作，保持原速，不是人工效率对照。账号手机号在成片中遮挡，Key、原始日志和登录状态不发布。

自动整表审计仍保留 4 个保守提示：未选的同组“内推”单选项与三个内部搜索框。原始判定未改写，独立原生树核对“无”、北京、没有工作经历以及两所学校已选中。34 项核对通过不等于附件、声明或企业服务器的可提交性通过；没有申请成功或服务器保存结论，也没有全过程变更审计结论。

在线录制模式只在独立宿主启用，不代表普通应用所有站点都有相同覆盖。运行方式：

```sh
node scripts/record-workspace-form.mjs --live-model --output=.backups/model-demo/take-1
```

在窗口里手动登录，在模型设置输入本次专用 Key，先准备申请选项，再发送“识别网申”，等计划完成后点击 App 顶部“自动填写”。录制数据仅保存在本地忽略目录。这个宿主限定面壁演示页面和虚构资料，不能当作无人值守投递脚本。
